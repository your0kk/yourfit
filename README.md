yourfit

моё приложение для тренировок на android. дизайн сделал в фигме.

есть домашние тренировки, улица и зал. можно создать локальный аккаунт, выбрать программу, пройти упражнения с таймером и посмотреть статистику.

для запуска открой эту папку в android studio, дождись синхронизации и нажми run с выбранным эмулятором или телефоном. для gradle используй jdk 21.

данные сохраняются на телефоне. калории приблизительные, для их расчёта нужно указать вес. напоминания пока сохраняют только настройки, а вопрос тренеру остаётся локальной заметкой.

сборка: gradlew.bat assembleDebug

apk после сборки: app/build/outputs/apk/debug/app-debug.apk
